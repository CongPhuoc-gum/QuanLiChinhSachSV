ALGORITHM: String Comparison & Weighted Scoring
─────────────────────────────────────────────────

1. NORMALIZATION:
   - Remove Vietnamese accents (á→a, é→e, etc.)
   - Convert to lowercase
   - Trim whitespace
   - Remove extra spaces

2. SIMILARITY CALCULATION:
   - Exact match → 1.0
   - Levenshtein distance: 1 - (distance / max_length)
   - Special handling for dates (DD/MM/YYYY)

3. WEIGHTED SCORING:
   overall_match = (ho_ten_similarity × 0.35) +
                   (id_similarity × 0.35) +
                   (others_similarity × 0.30)

4. STATUS DETERMINATION:
   if overall_match >= 0.95:
       status = APPROVED  (auto-approve, move to next stage)
   elif overall_match >= 0.80:
       status = WARNING   (admin review recommended)
   else:
       status = NEED_REVIEW  (send back to student)

WORKFLOW: Hồ Sơ Status Transitions
──────────────────────────────────

Before OCR:
  Status 2: Chờ thẩm định (has uploaded minh chứng)

After OCR Processing (POST /api/ho-so/{id}/process-ocr):
  
  IF all minh chứng APPROVED (all >= 95%):
    → Status 4 (Chờ Trưởng phòng duyệt)
    → Auto-approved, move to next approval stage
    → GhiChu: "Tự động duyệt từ OCR AI - Tất cả minh chứng hợp lệ"
  
  ELIF any minh chứng NEED_REVIEW (< 80%):
    → Status 3 (Đang bổ sung)
    → Student must resubmit with correct documents
    → GhiChu: "Phát hiện sai lệch trong OCR - Yêu cầu bổ sung minh chứng"
  
  ELIF some minh chứng WARNING (80-95%):
    → Status 2 (Chờ thẩm định) [No change]
    → Admin reviews detailed comparison results
    → Can manually override if appropriate

ERROR HANDLING: Gemini Vision API Retry Logic
──────────────────────────────────────────────

callGeminiVisionWithRetry($imageUrl, $prompt):
├─ Attempt 1: Initial call (30s timeout)
├─ Attempt 2: Retry after 2s backoff
├─ Attempt 3: Retry after 2s backoff
└─ Handles: Timeouts, rate limits (429), server errors (5xx)

If all attempts fail:
└─ Exception thrown
└─ Caught & logged in HoSoController
└─ Transaction rolled back
└─ Error response returned to client
└─ Admin notified via logs

DATABASE: PHAN_TICH_AI_HO_SO Table Schema
──────────────────────────────────────────

CREATE TABLE PHAN_TICH_AI_HO_SO (
  MaPhanTich BIGINT PRIMARY KEY AUTO_INCREMENT,
  MaHoSo BIGINT UNSIGNED FK → HO_SO(MaHoSo),
  LoaiTaiLieuOCR VARCHAR(50)  -- cccd|ho_khau|ho_ngheo|khai_sinh
  URLAnh LONGTEXT,             -- Cloudinary URL
  KetQuaDoiChieu JSON,         -- Complete comparison result
  TyLeKhop FLOAT(3,2),         -- Match rate 0.00-1.00
  DoTinCayOCR FLOAT(3,2),      -- Gemini confidence 0.00-1.00
  CanBaoLech JSON,             -- Array of discrepancies
  TrangThaiXuLy VARCHAR(50),   -- PENDING|APPROVED|WARNING|NEED_REVIEW
  ThoiGianPhanTich TIMESTAMP,  -- When OCR was processed
  GhiChuAdmin TEXT,            -- Admin notes
  
  INDEX idx_ma_ho_so (MaHoSo),
  INDEX idx_trang_thai (TrangThaiXuLy),
  INDEX idx_ty_le_khop (TyLeKhop)
);
